## Patterns

- ष-dittography after `पञ्च`: 2 instances (#4 `पञ्चषाः`, #8 `पञ्चषेभ्यः`), both emended by deleting the intrusive ष.

## Unverified

- #3 `जामितां` → `मुष्टिं`*: no dictionary or heritage-platform check available; `मुष्टिं` (fist) fits "showing" before the mole speech, `पाणिं` (hand) is the runner-up; a print re-check would settle whether the glyphs were misread.
- #5 `शोधितवन्तः` → `शोधितवन्तौ`*: grammatical but stylistic; plural-for-dual has Epic precedent, so this needs an editor's house-style decision, not a glyph check.
- Query (no block emitted): `पृच्छतु-वरः कः` (p042:P2) is an obscure compound in Narayana's imagined return ("`कार्यसाधनं विना कथं वा प्रत्यागच्छेयम्? पृच्छतु-वरः कः इति?`"); left as printed pending an editor's reading.
